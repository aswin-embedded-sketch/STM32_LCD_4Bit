# STM32 16×2 LCD Interfacing in 4-Bit Mode

## Overview

This project demonstrates interfacing a 16×2 LCD display with the STM32F446RE microcontroller using 4-bit mode.

In 4-bit mode, the LCD data is transmitted using only four data pins (D4–D7), which reduces the number of GPIO pins required compared to 8-bit mode.

The project uses GPIO pins to send commands and character data to the LCD.

---

## Components Used

- STM32F446RE Nucleo Board
- 16×2 LCD Display
- Potentiometer
- Jumper Wires
- Power Supply

---

## Features

- LCD interfacing using 4-bit mode
- LCD initialization
- Sends commands to the LCD
- Sends character data to the LCD
- Displays text on the first line
- Displays text on the second line
- Uses GPIO pins for LCD control

- STM32CubeIDE
- STM32CubeMX
- Proteus Professional
- C Programming Language
