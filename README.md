# STM32_LCD_4Bit
Interfacing a 16x2 LCD with STM32F446RE using 4-bit mode.
# **Project Description**
This project demonstrates interfacing a 16x2 LCD with STM32 using 4-bit mode.
The LCD is controlled using GPIO pins, and data is sent in two 4-bit nibbles instead of using all 8 data pins.
# **Hardware Used**
STM32F446RE Nucleo Board
16x2 LCD Display
Jumper Wires
Potentiometer (for LCD contrast)
# **Software Used**
STM32CubeIDE
STM32CubeMX
C Programming Language
